## 主要趋势

1. **CT_RMS 随频率下降整体上升**：400 kHz/180° 为 0.007 A，160 kHz/180° 为 1.687 A（约 241 倍），
   符合接近空载谐振（~148.6 kHz）电流抬升的预期。中间 390→380 kHz 有 0.002 A 级回落，属零点/量化噪声量级。
2. **CT_RMS 随移相角单调上升**（每个频率内 10°→180° 递增），12V 空载下最大仅 1.687 A，远低于 10 A 保护门限。
3. **IC2 原始捕获随移相角递增**（如 160 kHz：470→578），随频率下降整体上移（同一个相角下）——捕获窗口跟着 ARR 变大。
4. **LAG_DEG 低频端整体下移**：400 kHz/180° 为 +159.5°，160 kHz/180° 为 +80.4°；低相角端在高频出现负值（-150°～-180° 附近），相角越高越趋于收敛。
5. LAG_DEG 为**未应用补偿表的原始计算角**（`ARR/4+D/2` 模周期），未做空载补偿，不可直接当作 ZVS 判据。

## 复现方式

```powershell
python Tools/heater_sweep.py --port COM19 --on --freqs 400-160:-10 --phases 10-180:10 `
       --settle 1.0 --preflight 6 --abort-ct 10 --supply-v 12 \
       --out Tools/sweep_12V_unloaded.csv
python Tools/heater_sweep_fill.py --csv Tools/sweep_12V_unloaded.csv   # 补测 NA 点
```

安全措施：每个频点先回到 10° 再改频率（不在 180° 下调频）；`CT_RMS_A ≥ 10 A`、ADC 饱和、`FAULT`、
`HEATER` 掉落 任一触发即中止；结束时必发 `heater off`。本次全程未触发，`heater` 状态 450/450 为 ON。
