# IH01A：12V / 200kHz 低功率加热与 TP1941 零电流捕获

## 测试定位和供电

本分支只允许狭窄范围的**人工 RUN 低功率试验**，并不解锁正式温控或功率闭环。
默认自动申请的 USB-PD 固定电压上限为 **12V**，请求电流限制为
**不超过3A**；自动 EPR 关闭。适配器若不提供 12V Fixed PDO
（只有5V或9V），不会启动功率级。即使用户在 CLI 手动要求
更高电压，BenchRUN 也只有在**实际有效的12V合同**、实际母线电压
处于10.8–13.2V、合同电流≤3A时才有机会使能 PC6。

TIM1 时钟 128MHz，PSC=0，ARR=426（CubeMX `Period=426`），所以
`f = 128MHz/(426+1) ≈ 299.8kHz`，周期约3.34µs。
CH1 PWM1 CCR1=213；CH3 Combined PWM2 与内部 CH4 PWM1 组合：
`CCR3=D=round(angle*426/360)`，`CCR4=D+213`。
相位 **0～180° 全范围可选**（2026-11-02 取消 10°/20° 限制）；
0° 不产生有效差模激励，只用于观察逻辑波形/基线。角度越大差模
激励越强，超过 20° 仍属**未验证区域**，母线电流需自行确认。

## 硬件使能与停止条件

主界面选择 RUN 并按 R 是**唯一的人工请求入口**。随后
`thread_heater` 先执行 `Heater_Poll`，再由
`ConvController_BenchRunPoll` 逐项核对：
1. 手动POWER模式，RUN_REQUESTED状态，相位已下发（任意角度）；
2. 已确认的12V Fixed USB-PD合同，电流≤3A、采样母线10.8–13.2V；
3. ADC零点校准成功、POT/SYS温度有效且未过温
   （测试门限POT<70°C、SYS<60°C，最近更新≤250ms）；
4. DAC/COMP已初始化、TIM1逻辑PWM正常、无ADC/COMP保护故障
   或TIM1 BIF锁存。

满足时才拉高PC6使能FD2204。**没有时间预算**（2026-11-02 取消10秒限制）：
一直保持到用户 STOP、门控条件失效或保护故障为止。
RUN界面显示PC6开关状态与已运行秒数。改变相位不再中止运行
（角度只是手动观察量）；只有用户停止或保护动作才拉低PC6。

**快速保护**：COMP窗口低电平→TIM1硬件Break立即清除MOE；
`TIM1_BRK_UP_TRG_COM_IRQHandler` 再撤销PC6并锁存
`CONV_PROT_TIM1_BREAK`。ADC ISR每帧检查母线是否离开
约10.25–13.67V的原始码范围，异常立即撤销PC6；
ISR还累计上电后有效开关期间的完整ADC采样帧，
原10秒帧计数超时（CONV_PROT_BENCH_TIMEOUT，0x00010000）已取消，
帧计数只用于诊断，不再关断PC6。
最后一项能覆盖主循环阻塞但DMA中断仍工作的情况，**不等价于
独立硬件看门狗**；SysTick/ADC/MCU全部失效时仍需硬件保障。

## TP1941 → PA9 → TIM1_CH2

CubeMX 已设置 `PA9=TIM1_CH2`，上升沿、Direct TI2。
TP1941比较器检测的是电流过零；模拟链有一次反相，因此
使用捕获上升沿对应电流的**正向到负向过零**。
TIM1_CH2原本分配了DMA1_Channel3，仍保留.ioc/初始化，
**运行时没有调用DMA启动，也不使能CC2IE/CC2DE**。
只是开启TIM1_CC2E，在MiaoUI前台每次绘制时读最新的
`TIM1->CCR2`。200kHz下反复发生CC2OF属于预计现象，
不是精确记录了每个周期；该观测只能用于初步相位验证，
后续需要统计抖动时再启用连续循环DMA和更严谨的信号筛选。

给定电压差模基波由正变负的参考：
`t_V_ticks = ARR/4 + D/2`。
捕获的电流过零时间为`t_I_ticks=CCR2`，模周期取
`P=ARR+1=640`，最近半周期映射后的滞后角：
`phi_deg = wrap_signed(t_I-t_V, P) * 360/P`。
正号表示测得的电流过零**晚于**该电压过零参考。
若上升沿对应的实际电流过零极性不对，则会引入180°歧义，
必须用示波器实测TP1941输入和输出建立符号对应关系。
量化分辨率约`360/640=0.5625°/count`，UI显示0.1°不表示
物理精度为0.1°。0°相移时差模电压基波为0，相位标记无效。

主界面第三行显示目标角及CCR3/4，第四行显示
`IC2:<CCR2> L:<+/-相位角>`，最后一行P表示逻辑PWM、
E表示PC6。缺少有效CC2采样或0°激励时显示`IC2:-- L:--`。

## 建议实机顺序

先保持RUN=STOP且PC6为低，用示波器确认PA8/PA10 200kHz、
两个占空比和移动相位正确；再核对12V合同、
DAC+COMP±12A窗口、ADC电压/温度；将工件紧贴线圈，
确认实验区域安全且有外部断电手段；将相位设为10°，
**人工**选择RUN，观察母线电压/电流、TP1941模拟输入、
PA9比较器边沿和UI测得的CCR2/相位。先用短时间运行，
出现异常立即断开电源，之后再考虑20°实验。
不得以单次零点采集成功推断ZVS、ZCS或安全功率范围。
