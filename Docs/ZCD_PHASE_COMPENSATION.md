# IH01A · CT_ZERO / IC2 相位检测补偿（2026-11-04）

## 结论来源与适用性

依据此前“分析CT整流电路”对话**较新的 IC2 计数域拟合**，
采用固定锚点与三段线性频率校正，**不使用二维 LUT 或浮点计算**。
相位检测链路为 CT → 模拟调理/TP1941 → PA9/TIM1_CH2 输入捕获；
CC2 使用上升沿，前台按需读 CCR2，保持无 CC2 DMA 和中断。

空载模型的理论参照取
`L=30.5µH, C=37.6nF, DCR=0.151Ω`。该 DCR 是理论拟合
所用的静态参数，**不是带锅工作时的交流总等效电阻**。

针对空载测量的模型拟合结果，在160～330kHz约有≤2.1°
最大残差；在120～180°移相角的数据子集中最大约2.61°。
这些是历史空载拟合结果，不是带锅误差上限，也不能用于
保证零电压开关(ZVS)。原分析认为330～400kHz不能可靠外推。

## 公式（全部整数计算）

```text
f [kHz] = 128000 / (ARR + 1)
DeltaN [ticks] =
    58 + 0.105*(f-300) - 0.407*max(0,230-f)
       - 2.057*max(0,175-f)

RawLag = wrap180(360*(IC2 - (ARR/4+D/2))/(ARR+1))
CorrLag = wrap180(RawLag - 360*DeltaN/(ARR+1))
```

- `D` 为 `ConvPhase_Calculate()` 根据180°范围移相设定计算的CCR3。
- 正 `DeltaN` 表示检测过零落后，应从原始IC2中**减去**；
  在160kHz附近可能为负值，需**加回**对应计数。
- `DeltaN` 的58 ticks是300kHz的经验拟合锚点，绝对不是
  TP1941数据手册固定传播延迟。
- 固件采用 **实际TIM1计数周期** 算出Hz后求出补偿：
  `delta_milliticks = 58000 + 105*(Hz-300000)/1000
  - 407*max(0,230000-Hz)/1000 - 2057*max(0,175000-Hz)/1000`。
  随后转换为0.1°并做 ±180°回绕。整数舍入导致与
  数学连续模型的差别通常小于0.1°。

## 标定范围与测量可信状态

空载补偿被**有意限制**到：

- **频率：160～330kHz**，以TIM1实际ARR计算，不对150～159kHz、
  331～400kHz进行外推；
- **移相角：120～180°**（对更低移相角的误差尚无足够验证）；
- **CT_RMS去零点后≥0.050A**，且ADC必须有效、未饱和；
- **捕获必须有效且新鲜**，功率级实际开启时才显示角度。

满足这些条件只得到`FIT`（空载拟合域内）状态，
**不代表对工件变化、温升和比较器过驱动的校准已完成**。
该模型仅用于诊断显示和测试数据积累；不连接任何PLL、
ZVS自动追踪、瞬态保护或TIM1输出使能判据。
对于低电流，未来的功率控制应考虑保守开环策略，
不得静默使用原始Lag代替失效的补偿角闭环。

## 屏幕与串口格式

- Settings/Heater：`IC2`始终保持真实原始CCR2；
  `LagR`是原始计算角，`LagC`是补偿角；无法给出
  补偿角时屏幕附注`FREQ/PHASE/LOW CT/ADC`。
- UART `heater get`：`IC2`不变；`LAG_RAW_DEG`是原始计算角；
  `LAG_DEG`现在代表**补偿角**，不在有效标定范围时为`NA`。
  新增`LAG_QUAL=FIT/FREQ/PHASE/LOW_CT/ADC/NO_IC2`。
  此项响应协议有意变更了`LAG_DEG`的语义；旧的本地Agent
  需要更新其解析逻辑。
