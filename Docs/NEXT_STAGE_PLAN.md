# IH01A 下一阶段工作计划

**基线日期：2026-10-31。** 已通过用户实机基础测试：SSD1315 显示、四键交互、UI_OFF 休眠/唤醒；当前 `0x400`（1 KiB）C 堆配置能正常启动。**仍禁止实际感应加热功率输出。**

## 原则与依赖顺序

先固定可复现的**非加热基础平台**，再接入测量与故障检测，然后验证独立硬件保护，最后实现受控 PWM 和 UI 功能。PD 稳定性和安全保护是加热控制的前置条件；菜单美化和多语言可以并行，但不得影响这些前置条件的验收。

## 建议优先执行的下一轮任务

1. **冻结基础固件**：存档可运行的 `main` SHA、Keil 版本、`.ioc`、启动汇编、生成的 .map，记录堆 `0x400` / 栈 `0x400`。不要在没测量峰值前再次把堆置零。
2. **验证资源与实时性**：获取静态 RAM、堆/栈水位，使用 GPIO/时间戳实测每次 OLED SPI 发送耗时及 PD 回调间隔；不同适配器反复插拔，观察是否会重启/丢帧。
3. **整理电气约束**：根据最终原理图建立 `MCU 引脚 ↔ 传感器/比较器 ↔ MOS/驱动/功率级` 表，列出无加热条件下可以验证的安全功能。
4. **先完成安全链再接热负载**：硬件过流快速关闭、PWM_EN fail-safe、温度与输入电压异常锁存通过后，才能开始限流、分阶段的加热实验。

## 明确暂缓

- 无保护验证就启用 TIM1 PWM 或从 GUI 直接控制加热输出。
- 为消除 `_init_alloc` 问题而随意扩大堆、隐去错误或删掉必要 C 库重定向。
- 在 PD 时序未测前加入大面积整屏阻塞刷新、复杂图形动画或重量级实时任务。
- 在没有实际传感器数据时为 Data 页面填入模拟值并展示成真实测量。

**当前最有价值的紧接任务是：P0 资源/PD 时序基线 + P1 电气信号清单；完成后再决定闭环控制与 UI 具体布局。**

## 增量功能（2026-10-31，待 Keil/板端验收）

已为运行时 SSD1315 刷屏接入 SPI1 TX DMA（命令和 128B 页数据分别异步发送），
初始化命令仍同步发送；Display 菜单新增进入即全白的 Burn-in Test，
任意 L/R/ENTR/EXIT 按键退出。按钮消抖由 30ms 改 60ms，
L/R 的 DAS 由 400ms 改 800ms、连发周期 100ms 改 200ms；
参数窗口中 L 为减少、R 为增加。

验收要求：Keil 编译；DMA1_Channel1 IRQ 确认及 SPI NSS/D-C 波形；
连续动画+PD 协商及负载变化压力测试；全亮界面四键退出；
屏幕休眠/唤醒时若 DMA 尚在传输应能恢复；参数正反向步进及极值回绕。
全白测试可能加速 OLED 老化，应避免长时间无人值守。
