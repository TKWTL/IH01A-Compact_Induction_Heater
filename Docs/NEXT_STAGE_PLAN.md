# IH01A 下一阶段工作计划

**基线日期：2026-10-31。** 已通过用户实机基础测试：SSD1315 显示、四键交互、UI_OFF 休眠/唤醒；当前 `0x400`（1 KiB）C 堆配置能正常启动。**仍禁止实际感应加热功率输出。**

## 原则与依赖顺序

先固定可复现的**非加热基础平台**，再接入测量与故障检测，然后验证独立硬件保护，最后实现受控 PWM 和 UI 功能。PD 稳定性和安全保护是加热控制的前置条件；菜单美化和多语言可以并行，但不得影响这些前置条件的验收。

## 建议优先执行的下一轮任务

1. **冻结基础固件**：存档可运行的 `main` SHA、Keil 版本、`.ioc`、启动汇编、生成的 .map，记录堆 `0x400` / 栈 `0x400`。不要在没测量峰值前再次把堆置零。
2. **验证资源与实时性**：获取静态 RAM、堆/栈水位，使用 GPIO/时间戳实测每次 OLED SPI 发送耗时及 PD 回调间隔；不同适配器反复插拔，观察是否会重启/丢帧。
3. **整理电气约束**：根据最终原理图建立 `MCU 引脚 ↔ 传感器/比较器 ↔ MOS/驱动/功率级` 表，列出无加热条件下可以验证的安全功能。
4. **先完成安全链再接热负载**：硬件过流快速关闭、PWM_EN fail-safe、温度与输入电压异常锁存通过后，才能开始限流、分阶段的加热实验。

## 明确暂缓

- 无保护验证就启用 TIM1 PWM 或从 GUI 直接控制加热输出。
- 为消除 `_init_alloc` 问题而随意扩大堆、隐去错误或删掉必要 C 库重定向。
- 在 PD 时序未测前加入大面积整屏阻塞刷新、复杂图形动画或重量级实时任务。
- 在没有实际传感器数据时为 Data 页面填入模拟值并展示成真实测量。

**当前最有价值的紧接任务是：P0 资源/PD 时序基线 + P1 电气信号清单；完成后再决定闭环控制与 UI 具体布局。**

验收要求：Keil 编译；DMA1_Channel1 IRQ 确认及 SPI NSS/D-C 波形；

## 外设驱动后续规范（2026-11-01，尚未实施）

- **USART：统一 DMA + 环形缓冲区的后台双向服务。**
  RX DMA circular 接收，结合 UART IDLE 或 DMA 读写位置差值更新 RX
  队列；TX 从静态环形缓冲区按段启动 DMA，完成回调继续发送剩余数据。
  不在 UI/PD 主循环使用阻塞 HAL_UART_Transmit/Receive；明确溢出、
  断帧、重启、错误恢复与多调用方串行化。先核对 CubeMX 资源及 DMA
  通道冲突，当前暂不重构 USART。
- **M24C32（I²C）：后续使用中断驱动的非阻塞状态机。**
  读写采用 HAL_I2C_Mem_Read_IT / HAL_I2C_Mem_Write_IT 或兼容的
  IT API；跨 32B 页写边界拆分，写周期完成使用定时退避/ACK 检测，
  不允许在 PD 回调阻塞等待 EEPROM 内部写周期；设置错误与超时恢复。
  暂不在工程中初始化、读写或调用该 EEPROM。
- **OLED**：运行时与初始化统一用 SPI1 TX DMA，初始化允许同步等待
  DMA IRQ，运行时严格后台服务。后续测 ROM（.map）、DMA IRQ
  启动时序、PD 调度延迟，不凭函数替换本身宣称节省多少 Flash。

## PowerControl 移植依赖（2026-11-01）

本次完成 **v1 仅监测骨架**：新 `power_control.c/h` 已进入 Keil，旧 G474
HRTIM/浮点控制源保留为未编译参考。TIM6 采样时钟与 TIM1 PWM 时钟
解耦，ADC-DMA 事件驱动定点状态机。链接文件已经设置 RAM ISR 与
SRAM 向量表，**这只是代码接入，不代表已经通过板端编译/测试**。

下一轮按顺序：
1. 在 Keil 中确认 scatter-loading 完成、.ih_ramfunc 位于 0x20008000 区、VTOR=0x20008F00，并核对堆栈位置；断点确认 ISR_TIME 高/低电平和 ADC 8 路顺序。
2. 使用示波器验证 TIM6 TRGO=20kHz 的实际 ADC 完成率、ISR_TIME 高脉宽和 ISR_LOAD 饱和约 75.8% 的预期；抓 ADC OVR/HT/TC 积压状态，不允许漏帧后自动恢复输出。
3. 取得桥臂原理图、TIM1 CH1/CH3/CH2 真实用途、负载谐振频率/安全频率区间、PWM_EN 有效极性和 COMP/Break 硬件闭锁结果；在这些信息明确后实现移相、调频、间歇的硬件输出映射及安全同步。
4. 进行限流无功率→受限功率的分阶段保护测试，建立输入/母线/电流/NTC 的分压比和标定后，再考虑真正的闭环调功。
