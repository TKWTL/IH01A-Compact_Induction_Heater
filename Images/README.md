## Testing

- **#001 移相驱动**：300 kHz 60°、120° 的实验波形。
- **#002 短脉冲检锅**：无锅、利乐牛奶包装、锅具贴合、1.6 mm 间距的原始截图，与 [检锅报告](../Docs/Experiments/PAN_DETECTION_PULSE_RINGDOWN_STUDY_2026-11-10.md) 对照。
- **#003 模拟信号链路**：300 kHz 空载和标称 71 W 测试工况下，电容电压与 CT、零电流检测、精密整流输出。
- **#004 半桥开关沿**：300 kHz 空载时上升沿与下降沿。
- **pan_*.svg**：从 #002 采样记录整理的描述性统计图，不得将 CCR2 相位计数图解释成精确时域余振包络。
